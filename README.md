# Quidly Merchant

A modern, responsive merchant payment dashboard prototype designed to give businesses a clear and intuitive way to manage their payment operations.

## 🚀 Overview

**Quidly Merchant** is a front-end dashboard concept focused on creating a seamless merchant experience across payments, transactions, invoicing, accounts, settlements, and configuration.

The project brings together the merchant workflows from the earlier Quidly interface and the newer dashboard structure into a more responsive and consistent user experience.

This repository contains the current **HTML/CSS/JavaScript demonstration of the Quidly Merchant web application**.

## 🎨 User Experience

The dashboard was designed around a merchant-first user journey, with an emphasis on:

- Clear information hierarchy
- Responsive navigation
- Consistent sidebar interactions
- Accessible merchant workflows
- Mobile-friendly layouts
- Interactive dashboard components
- Consistent navigation across merchant operations

## 📱 Responsive Design

The interface is designed to adapt across:

- Desktop
- Tablet
- Mobile

The sidebar navigation transitions into a mobile-friendly navigation experience on smaller screens while maintaining access to the main merchant workflows.

## ▶️ Running the Demo

Clone the repository:

```bash
git clone https://github.com/aanuoluwapoojedele-debug/quidly-merchant.git
```

Open the project:

```bash
cd quidly-merchant
```

Then open:

```text
quidly_dashboard_v5_green_glow.html
```

in a modern web browser.

For development, the project can also be opened in **Visual Studio Code** and run with a local development server such as Live Server.
